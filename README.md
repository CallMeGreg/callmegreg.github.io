# [callmegreg.github.io](https://callmegreg.github.io/)

My personal site: projects, published work, and a playground of small games and
tools. Built with React and Vite.

The site defaults to dark mode. Use the theme toggle in the home page header
(or the bottom-right corner of an app) to switch to light mode. Your choice is
saved in `localStorage` as `site.theme` and applies across routes and reloads,
independently of each app's Reset control. Embedded games and third-party players
keep their own appearance.
